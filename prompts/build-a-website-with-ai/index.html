Build a website with one AI prompt

One copy-paste prompt gets you a working single-page site. A few follow-ups make it yours and put it online for free.

You do not need a website builder subscription to get a clean one-page site for a side project, a portfolio, an event or a small business. Today's AI chats can write a complete page as a single HTML file that opens in any browser, with no setup and no code knowledge needed.

The trick is a detailed first prompt. Tell the AI exactly what the page is for, who it's for and what sections you want, and ask for everything in one file. Then use short follow-up prompts to fix anything you don't like. When you are happy, free hosts like GitHub Pages, Netlify or Cloudflare Pages can put it online.

The prompts

Replace every [bracket] with your real details, then paste into ChatGPT, Claude, Gemini or Grok.

Prompt 1

The one-prompt website

Build a complete one-page website as a single HTML file with all CSS inside a style tag and no external libraries. It is for [what it is, e.g. my dog-walking business in Austin]. The audience is [who]. Include: a hero section with a headline and one button, [3] sections about [topics], a simple contact section with [email/phone], and a footer. Style: [e.g. warm, modern, lots of white space], main color [color]. It must look good on phones. Write real, specific copy, not lorem ipsum. Return only the code.

Save the reply as index.html and double-click it to open it in your browser.

Prompt 2

Fix what you see

Here is my current website code: [paste code]. Make these changes and return the full updated file: [e.g. make the headline bigger, change the button to green, add a pricing section with 3 options]. Do not change anything else.

Asking for the full file avoids mistakes from pasting partial snippets.

Prompt 3

Polish and accessibility

Review this HTML page for a beginner: [paste code]. Improve it so it has a good page title and meta description, readable font sizes on mobile, enough color contrast, alt text on images and a favicon emoji. Return the full updated file and list what you changed.

A quick pass like this makes a big difference on phones.

Prompt 4

Publish it free

I have a single index.html file and no coding experience. Walk me step by step through publishing it for free on [GitHub Pages / Netlify Drop / Cloudflare Pages], including how to connect a custom domain later. Assume I have never used these tools.

Netlify Drop lets you drag and drop the file. GitHub Pages is free and lasts.

Worked example

Situation: you run a weekend pottery class and want a page to send people to.

Prompt 1 with "pottery classes for beginners in Columbus, sections: what you'll make, schedule, what to bring, earthy terracotta color" produces a full page. Opening it, you decide the schedule should be a table, so Prompt 2 asks for that change. Prompt 3 adds a proper title and mobile tweaks. Prompt 4 walks you through Netlify Drop, and you have a live link to share the same afternoon.

FAQ

Can AI really build a whole website from one prompt?

For a simple one-page site, yes. A detailed prompt usually gets a working page on the first try. More complex sites with logins, payments or databases need more steps.

Do I need to know how to code?

No. You copy the code the AI gives you into a file named index.html. Follow-up prompts handle the changes, and you can ask the AI to explain anything.

Where can I host the website for free?

GitHub Pages, Netlify and Cloudflare Pages all have free plans that work well for single-page sites. A custom domain is optional and usually costs about the price of a lunch per year.
